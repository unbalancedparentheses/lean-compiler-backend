# Mutable integer width merging

Private candidate based on b246312; source/build identity `53a64ae791d30a1bc83b31fc994b37403597620dbf4f787d09a4499df8833491`. No main source edits or commits.

Upstream QBE util.c clsmerge combines mutable integer word/long definitions into word class. LCB now does the same while retaining each original parameter, instruction and explicit phi width. Newly generated join phis use the merged word class. Before unreachable-block pruning or SSA renaming, every operand use of a mixed name must have integer word role; long or floating roles are refused even if a particular reaching definition was long. The guard also runs from public SSA.construct. Integer/FP definition mixing and differing FP precisions remain refused. No implicit widening or general type relaxation is introduced.

The raw-use role audit covers phi/return/branch, copy/cast/conversion, binary arithmetic and word shift counts, division/comparisons, memory value/address roles, allocations, variadic-list addresses, blit pointers, assigned and effect-only calls, indirect targets and environment arguments. Existing IR width utilities are reused for conversions, unary inputs, shifts and stores. No shared generic typed-operand utility exists, so the local exhaustive operation match is explicitly audited against Validate.lean.

Final frozen v2 campaign passes on all five targets: 10 functions ×128 seeded uint64 inputs ×9 count values =11,520 independent C checks per backend. Three LCB modes plus unchanged original QBE give 172,800 LCB checks and 57,600 QBE checks. Cases cover both sequential assignment orders, long and word parameter reuse, branch and loop joins, long result definitions using separately extended inputs, oversized shift counts, word call arguments, effect-only call effects, single-precision bit casts and word memory operations. Each target also passes 30 Python/interpreter comparisons, 28 raw-use/type negatives rejected by both compilers, a first-path refusal, historical-before refusal, and deliberately wrong word arithmetic detected by C exit 1. No floating arithmetic on arbitrary bit patterns is used.

Linux ARM executes natively in Docker; Linux x86/RV use QEMU; Apple ARM executes natively and Apple x86 via Rosetta. Five missing-tool emission-only runs invoke neither C nor QBE tools. Native CLI with --require-native and explicit QBE passes. Fresh units and all 147 exact unchanged proof-audit assertions pass; this does not extend proof coverage. The existing SSA regression passes 22 functions and 197 Python/interpreter cases, deterministic renaming, native LCB/QBE execution and corruption control.

Source, helper, unit source, compiler identity manifest and immutable before/after compiler hashes agree before/after final campaign. Exact fixtures, C oracles, generated assembly/executables and reports are retained. Linux guest/host SHA barriers match 70 files per target. Earlier nine-function campaign v1 remains privately retained; this package binds only final v2 helper.

The separate explicit-long-phi self-definition diagnostic triggers an original-QBE SSA-invariant abort; LCB refuses it during later SSA validation. It is not treated as accepted upstream semantics or a passing test. Dead-block probes separately show original QBE refusing both an unreachable long use and an unreachable word definition which makes a live long use invalid. These reference diagnostics are preserved under reference-edge-probes/.
